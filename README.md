# Matrix-бот «Нио-Люмия»

> Matrix-бот с локальной LLM-моделью, который отвечает в комнатах от лица персонажа «Нио-Люмия».  
> Работает без платных API — вся генерация идёт локально через Ollama.

[![Ollama](https://img.shields.io/badge/Ollama-gemma4%3Ae2b-purple)](https://ollama.com/)


## 📖 Краткое описание

**Matrix-бот «Нио-Люмия»** — это чат-бот для Matrix, который подключается к серверу, слушает сообщения в комнатах и отвечает на них через локальную LLM. Характер и стиль общения задаются system-промптом в `config.py`.

Бот не использует внешние API — вся генерация идёт локально через **Ollama** с моделью `gemma4:e2b`. Это значит:
- ✅ Нет платных подписок
- ✅ Нет утечки данных наружу
---

## ✨ Возможности

- 🔐 Авторизация в Matrix по токену или паролю
- 💬 Приём и отправка текстовых сообщений в комнатах
- 🤝 Автопринятие приглашений в комнаты
- 🧠 Интеграция с локальной LLM через OpenAI-совместимый API
- 🎭 Кастомизация характера бота через system-промпт
- 📝 Логирование событий (logbook)
- ⚙️ Конфигурация через `.env`
- 🛡 Обработка ошибок LLM с fallback-ответом

## ⚙️ Системные требования

| Компонент | Минимум | Рекомендуется |
|-----------|---------|---------------|
| **ОС** | Windows 10 | Arch Linux / CachyOS / любой Linux с ядром 6+ |
| **Процессор** | 4+ ядра |8+ ядер (Intel Core i7 / AMD Ryzen 7 и выше) |
| **ОЗУ** | 8 ГБ | 16+ ГБ |
| **Диск** | 5 ГБ свободно | 10+ ГБ (модель + кеш) |
| **GPU** | NVIDIA RTX 3050 Laptop (4 ГБ VRAM) | NVIDIA RTX 4060 / 4070 (8+ ГБ VRAM) |
| **Интернет** | для первого запуска и связи с Matrix | постоянное подключение |

> ⚠️ **Про ОС:** на Windows 10+ библиотеки для E2EE-шифрования (`python-olm` в связке с `matrix-nio`) не работают. Полноценная поддержка E2EE — только на Linux. Для базовых сценариев (текстовые комнаты без шифрования) Windows 10/11 подходит.
